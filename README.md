# Моя конфигурация NixOS

Этот репозиторий содержит мою личную конфигурацию NixOS.  
Я использую **Flakes** и **Home Manager**, чтобы описать всю систему декларативно.

## Что внутри

- **flake.nix** — точка входа. Описывает всю систему.
- **hosts/** — настройки для конкретных машин (сейчас только `nixos-vrn`).
- **modules/** — переиспользуемые модули NixOS:
  - `core/` — загрузчик, сеть, локаль.
  - `hardware/` — драйверы (NVIDIA), звук.
  - `desktop/` — окружение рабочего стола.
  - `users/` — пользователь и системные пакеты.
- **home/** — конфигурация пользователя через Home Manager.
- **waybar/** — настройки панели Waybar.

## Как собрать

```bash
sudo nixos-rebuild switch --flake .#nixos-vrn
